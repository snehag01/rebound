# Rebound Roadmap

This folder holds **dated snapshots** of the product roadmap. Each time the roadmap
meaningfully changes, add a **new file** — never edit an old one — using `mmddyyyy` versioning:

```
roadmap/roadmap_<mmddyyyy>.md      e.g. roadmap_07072026.md  (July 7, 2026)
```

- The file with the **most recent date** is the current roadmap.
- Older files are preserved as history, so you can see how the plan evolved.
- Keep the format consistent (status legend + versioned milestones) so snapshots are diffable.
