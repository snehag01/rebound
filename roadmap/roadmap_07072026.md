## v0.2.0 — Local Application Dashboard 🚧 *(building now)*
A **React localhost dashboard** that visualizes the whole job search from a **local datastore** — no cloud, all on the user's machine. Claude Code is the "writer"; the dashboard is the "reader."

**Data flow:** `/rebound:track` (and `/rebound:tailor`) write to `~/.rebound/data/tracker.json`; a Vite dev-server middleware serves it to a React app at `localhost`.

- 🚧 **Local datastore** `~/.rebound/data/tracker.json` — client info + applications (company, role, JobId, status, fit%, sponsor, résumé file, dates, source, notes).
- 🚧 **Client header** — name/title + "last updated" + weekly-goal progress bar.
- 🚧 **Headline metrics (stat cards)** — résumés curated, companies applied to, applications total, interviews (screen+onsite), offers, response rate.
- 🚧 **Pipeline funnel** — curated → applied → screen → onsite → offer (visual bars).
- 🚧 **Applications over time** — weekly bar chart to show momentum.
- 🚧 **Fit-score distribution** — how strong the targeted roles are (bucketed bars).
- 🚧 **Company/application table** — status pills, fit%, sponsor flag, the exact **résumé file** curated for each, and dates; sortable/filterable.
- 🚧 **Progress vs. goal + streak** — visual bars tying activity to the user's runway.
- 🚧 **Rich CSS** — polished dark theme, comeback-energy accent, animated bars; pure CSS/SVG charts (no heavy chart libs).
- 🔜 `/rebound:track add|update` command so Claude records/updates applications in one line.
- 🔜 `/rebound:dashboard` command to launch it (`npm run dev`).

**Principle:** all analytics computed **locally on the client's computer**; nothing leaves the machine. Sensitive `situation` data is never rendered publicly.

## v0.7.0 — Profile & Presence Optimization 🧭
Strengthen the candidate's *whole* presence, not just the résumé — recruiters search LinkedIn and GitHub before they ever open a PDF. Honest, section-by-section coaching driven by the same private profile.

- 🧭 **`/rebound:polish <linkedin-url | export>`** — read the user's LinkedIn (pasted text / PDF export) and give **section-by-section** upgrades:
  - **Headline** — keyword-rich, role-targeted, value-first (not just "Software Engineer at X").
  - **About / Summary** — the first two lines are the hook shown before "…see more"; story + proof + keywords.
  - **Experience** — mirror the résumé's honest, metric-led bullets; keep titles/dates consistent.
  - **Skills & endorsements** — front-load the exact skills recruiters filter on for the target role.
  - **Featured** — surface publications, OSS, talks, and the privacy-safe "career one-pager".
  - **Recommendations** — who to ask, and a ready request template.
  - **Banner, photo, custom URL, Open-to-Work** visibility settings.
  - **Activity / content** — a light, sustainable posting rhythm to stay on recruiters' radar.
- 🧭 **Recruiter-search (SEO) alignment** — keyword coverage vs. target roles so the profile actually surfaces in recruiter searches.
- 🧭 **Beyond LinkedIn** — GitHub profile README + pinned repos and a simple portfolio, with one consistent narrative across all of them.
- 🧭 **Dashboard tie-in** — a "profile health" checklist/score with quick wins.

**Principle:** same honesty-first rules — improve how the truth is *presented*, never invent it. The private situation never goes on a public profile.

## v0.8.0 — AI Job-Hunt Toolkit & Strategy 🧭
Rebound as a **strategist**, not just a document generator: an honestly-evaluated map of the AI job-hunting landscape plus a personalized game plan sized to the user's runway.

- 🧭 **`/rebound:strategy`** — a tailored playbook: where to spend time, application cadence, referral-first outreach, warm-vs-cold ratio, and weekly targets tied to the timeline.
- 🧭 **Curated, honestly-rated tool guide** — what each category actually does and its pitfalls, mapped to the proven **Build → Optimize → Apply → Track → Prep** loop:
  - *Résumé & ATS:* Jobscan, Rezi (keyword/ATS match scoring).
  - *Profile / LinkedIn:* Careerflow (LinkedIn optimizer, mock interviews).
  - *Role matching:* Jobright.ai and board/LinkedIn fit scoring.
  - *Auto-apply:* AIApply, FastApply, Sonara, LoopCV — **with a candid warning** that mass auto-apply usually lowers quality and response rate; Rebound favors targeted, referral-led applying.
  - *Tracking:* Teal (Kanban + match score) — Rebound's own dashboard already covers this locally.
  - *Interview prep:* Crystal (communication-style insights) and role-specific mock loops.
- 🧭 **Evidence-based nudges** — strategically tailored applications show materially higher interview rates (~2.5×) than spray-and-pray; Rebound optimizes for *fewer, better* applications.
- 🧭 **Live refresh** — an opt-in periodic web scan to keep the tool guide current as the landscape shifts.

**Rebound's stance:** honesty-first and local-first. We recommend complementary tools transparently, never spam, and never trade the user's data for convenience.

### Principles that don't change
1. **Base résumé is the source of truth** — never fabricate.
2. **Honesty-first** — no claimed expertise in unused tech.
3. **Primary over secondary** — relevant secondary skills support, never headline.
4. **The situation is private** — sponsorship/timeline data stays local, never in a résumé, never sent anywhere.
5. **Local-first data** — the datastore and all analytics live on the user's machine.
