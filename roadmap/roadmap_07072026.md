## v0.1.0 — Foundation (current) ✅
The honesty-first résumé engine and private profile.

- ✅ `/rebound:start` — onboarding: read base résumé, build private profile, capture the sensitive **situation** (work authorization, timeline) — stored locally only.
- ✅ `/rebound:tailor <JD|URL>` — curate from base résumé → ATS-safe **`.docx` + text-based `.pdf`**; Workday/board JSON parsing; gap-asking; honesty flags; primary-over-secondary; folder logic (`--out` or `<Name>_resumes`).
- ✅ `/rebound:profile` — view/update profile incl. private situation.
- ✅ `skills/resume-export` — generic JSON → `.docx` (`build_resume.py`) + verified text-layer PDF (`to_pdf.py`, LibreOffice → Word → docx2pdf).
- ✅ `skills/resume-tailoring` — the method (fit analysis, gap handling, fast-learner framing).
- ✅ `skills/profile-memory` — schema + private-situation rules.
- ✅ `/rebound:match` (basic) — score & rank pasted roles by fit %.
- ✅ `/rebound:rise` (basic) — supportive, runway-aware check-in.

### Principles that don't change
1. **Base résumé is the source of truth** — never fabricate.
2. **Honesty-first** — no claimed expertise in unused tech; label "working knowledge"/"familiar".
3. **Primary over secondary** — relevant secondary skills support, never headline over real strengths.
4. **The situation is private** — visa/timeline data stays local, never in a résumé, never sent anywhere.
