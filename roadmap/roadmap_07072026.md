## v0.2.0 — Local Application Dashboard 🚧 *(building now)*
A **React localhost dashboard** that visualizes the whole job search from a **local datastore** — no cloud, all on the user's machine. Claude Code is the "writer"; the dashboard is the "reader."

**Data flow:** `/rebound:track` (and `/rebound:tailor`) write to `~/.rebound/data/tracker.json`; a Vite dev-server middleware serves it to a React app at `localhost`.

- 🚧 **Local datastore** `~/.rebound/data/tracker.json` — client info + applications (company, role, JobId, status, fit%, sponsor, résumé file, dates, source, notes).
- 🚧 **Client header** — name/title + "last updated" + weekly-goal progress bar.
- 🚧 **Headline metrics (stat cards)** — résumés curated, companies applied to, applications total, interviews (screen+onsite), offers, response rate.
- 🚧 **Pipeline funnel** — curated → applied → screen → onsite → offer (visual bars).
- 🚧 **Applications over time** — weekly bar chart to show momentum.
- 🚧 **Fit-score distribution** — how strong the targeted roles are (bucketed bars).
- 🚧 **Company/application table** — status pills, fit%, sponsor flag, the exact **résumé file** curated for each, and dates; sortable/filterable.
- 🚧 **Progress vs. goal + streak** — visual bars tying activity to the user's runway.
- 🚧 **Rich CSS** — polished dark theme, comeback-energy accent, animated bars; pure CSS/SVG charts (no heavy chart libs).
- 🔜 `/rebound:track add|update` command so Claude records/updates applications in one line.
- 🔜 `/rebound:dashboard` command to launch it (`npm run dev`).

**Principle:** all analytics computed **locally on the client's computer**; nothing leaves the machine. Sensitive `situation` data is never rendered publicly.

### Principles that don't change
1. **Base résumé is the source of truth** — never fabricate.
2. **Honesty-first** — no claimed expertise in unused tech.
3. **Primary over secondary** — relevant secondary skills support, never headline.
4. **The situation is private** — sponsorship/timeline data stays local, never in a résumé, never sent anywhere.
5. **Local-first data** — the datastore and all analytics live on the user's machine.
